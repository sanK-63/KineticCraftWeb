# KineticCraft Website

Glassmorphism-styled website for KineticCraft Minecraft launcher.

## Pages
- index.html - Main page
- download.html - Download page
- auth.html - Authorization/Registration
- profile.html - User profile
- changelog.html - Updates
- reviews.html - Reviews

## Features
- Glassmorphism design
- Theme toggle (light/dark)
- User registration via Supabase
- Responsive design
